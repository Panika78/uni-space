# Uni Space — согласованный дизайн-референс v5

**Задача:** [issue #44 — Comprehensive interface refinement](https://github.com/Panika78/uni-space/issues/44).

## Файл

[Открыть интерактивный HTML v5](uni-space-redesign-v5.html) — автономный визуальный концепт. Открывается локально в браузере, содержит встроенные CSS/JS и демонстрационные данные.

Это **не рабочий frontend**, не источник API-логики и не замена архитектурной документации. Не копировать демонстрационную авторизацию, сохранение заявлений, mock-данные или маршруты в реальное приложение. При реализации переписать стили и композиции в существующие React-компоненты, сохранив серверные проверки, API и бизнес-процессы. Отдельные экраны макета могут иллюстрировать состояние, но не подтверждают готовность функциональности MVP 2 / Extended.

## Согласованные особенности

- Кремово-бордовая палитра, умеренные иконки, читаемая типографика, спокойный декоративный фон без резких цветовых границ.
- Профиль с декоративной иллюстрацией здания и выровненной сеткой секций.
- Расписание с хронологической вертикальной компоновкой, **режимы «День» и «Неделя» и на мобильном**. В режиме «Неделя» скрывается селектор ПН–ВС и показываются все дни с вертикальными списками занятий.
- Читаемые статусы переноса/отмены, поля заявлений и сессии, понятные пустые состояния.
- Плавные переходы вкладок, меню и содержимого с поддержкой `prefers-reduced-motion`.
- Адаптация от 360 px до крупных экранов 2560 × 1440.

## Как использовать

1. Открыть HTML в браузере и посмотреть внешний вид в широком и мобильном viewport.
2. Сопоставить отдельные экраны с существующими роутами из `frontend/src/app/router.tsx`.
3. Применять дизайн **поэтапно**, проверяя реальные загрузку, ошибки, пустые данные, формы, роли и адаптивность.
4. Критерии приёмки, ограничения и объём работ — в issue #44; функциональные контракты — в `docs/PRD.md`, `docs/API.md`, `docs/AUTH.md` и `AGENTS.md`.

**Важно:** документационный PR с этим референсом не закрывает issue #44. Для рабочего UI потребуется отдельный PR с реализацией и тестами.
