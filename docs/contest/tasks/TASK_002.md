# TASK-002 — Подготовка Frontend

## 1. Цель задачи

Создать техническую основу пользовательского интерфейса Uni Space на React, TypeScript и Vite, настроить маршрутизацию, тестирование и взаимодействие с backend.

**Задача:** [Issue #3](https://github.com/Panika78/uni-space/issues/3)

**Реализация:** [PR #23](https://github.com/Panika78/uni-space/pull/23)

## 2. Использование ИИ

**Инструмент:** OpenAI Codex.

Разработка выполнялась ИИ-агентом на основе GitHub Issue, AGENTS.md и технических спецификаций проекта.

Работа включала три основных этапа:

1. **Реализация.** Агент подготовил frontend, настроил зависимости, маршрутизацию, тесты и взаимодействие с backend.
2. **Независимое ревью.** Отдельный агент проверил корректность реализации и взаимодействие frontend с backend.
3. **Исправление замечаний.** По результатам ревью агенту-разработчику были переданы обнаруженные ошибки и конкретные требования к исправлению.

## 3. Результаты

В рамках TASK-002 реализованы:

- Frontend на React, TypeScript и Vite.
- Маршрутизация с использованием React Router.
- Интеграция Tailwind CSS и настройка shadcn/ui.
- Подключение TanStack Query.
- Тестирование через Vitest и React Testing Library.
- Проксирование API-запросов к backend.
- Минимальный интерфейс для проверки навигации.

**Обнаруженные и исправленные проблемы:**

- **F-01 (Medium).** Некорректная загрузка переменной `API_PROXY_TARGET` из `.env`. Исправлено с использованием `loadEnv`, добавлен регрессионный тест.
- **F-02 (Low).** Несоответствие зафиксированных версий Node.js и npm. Версии согласованы в конфигурации и документации.

## 4. Ручная работа

- Проверена доступность backend и корректность ответов API.
- Проверена работа Vite proxy: запросы напрямую и через proxy возвращали идентичный JSON со статусом 200 OK.
- Проверено отображение страниц, включая мобильную ширину 360 px.
- Выполнена чистая Docker-сборка backend с `--no-cache`.
