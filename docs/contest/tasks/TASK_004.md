# TASK-004 — Настройка автоматических проверок проекта

## 1. Цель задачи

Настроить автоматическую проверку backend, frontend, PostgreSQL, миграций Alembic и сгенерированных API-типов при изменениях в проекте.

**Задача:** [Issue #5](https://github.com/Panika78/uni-space/issues/5)  
**Реализация:** [PR #25](https://github.com/Panika78/uni-space/pull/25)

## 2. Использование ИИ

**Инструмент:** OpenAI Codex.

ИИ-агенту была поручена реализация TASK-004 по GitHub Issue и спецификациям проекта. После создания PR проводилось независимое ревью, затем исправлялись обнаруженные проблемы и повторно проверялась работа CI.

По описанию PR, в ходе проверок устранены замечания **F-01–F-06**: проверка согласованности lock-файла, реальное подключение к тестовой PostgreSQL, регрессионная проверка Compose healthcheck, фиксация версии Python, охват исходников Prettier и очистка тестовой БД перед проверкой миграций.

Отдельно с помощью ИИ рассматривался риск появления пароля PostgreSQL в traceback pytest и логах GitHub Actions. Агенту поручалась оценка риска без изменения кода.
